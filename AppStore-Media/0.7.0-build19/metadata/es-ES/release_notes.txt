Prueba gratuita de 3 días desde la primera apertura, sin cobro automático al finalizar. Después se necesita una suscripción anual. Precio base en EE. UU.: 3 USD al año; el App Store muestra el precio local. El cobro comienza solo al confirmar la compra. La suscripción adquirida se renueva anualmente, salvo cancelación al menos 24 horas antes de finalizar el periodo. Puedes restaurar compras y gestionar o cancelar la suscripción desde la app. Las tarifas de API del proveedor de IA son independientes.
