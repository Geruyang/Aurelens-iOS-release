Help with Aurelens

Report app issues, accessibility feedback, data corrections or privacy questions through our GitHub support centre.

Open a support request

Useful details

  • App version, device model and iOS version.
  • When the issue occurred and steps to reproduce it.
  • For market-data issues, the selected timeframe and displayed data timestamp.

Protect your information

GitHub issues are public. Do not post API keys, passwords, verification codes, Apple Account information, financial-account details, identity documents or other sensitive information. Remove private content from screenshots.

Languages and AI access

The app interface is available in English and Simplified Chinese. AI questions require your own OpenAI, DeepSeek or GLM API key; provider charges may apply.

Aurelens is a research tool. It does not execute trades; price zones, probability estimates and event analysis are not investment advice.
