隐私政策

AutoGolden 是面向伦敦金现货 XAU/USD 的市场数据与研究工具。运营者为 AutoGolden 个人开发者。如有隐私请求，请使用支持页面联系。

我们不做什么

  • 不连接银行、券商或支付账户，不执行交易，也不保管资产。
  • 不使用广告 SDK，不进行跨应用跟踪，不出售个人信息。
  • 不要求或保存第三方 AI 服务的网站登录密码。

设备本地信息

语言、模型选择、提醒开关、手动录入的成本与克数、最近对话保存在应用沙盒。模型 API Key 保存在 Apple Keychain。你可在应用内清除手动持仓；清空 API Key 并保存可移除相应 Keychain 项。

外部服务与传输

应用会向同花顺公开行情接口、美国劳工统计局 BLS、GDELT 发出功能所需网络请求。仅在你主动发起 Agent 请求或连接测试并明确同意后，应用才会向你选择的 OpenAI、DeepSeek 或智谱 GLM 服务发送请求。

Agent 请求可能包含你的问题、当前行情和指标摘要、事件/新闻摘要，以及必要的手动持仓摘要。这些服务可能接收标准网络信息，例如 IP 地址、请求时间和技术日志，并依各自隐私政策处理。请勿输入不必要的敏感信息。

通知与控制

通知默认关闭，仅在你开启点位提醒并授予系统权限后使用。你可关闭实时数据、通知和 Agent 数据发送同意。iOS 后台刷新由系统决定。

更新与请求

如需访问、删除或更正设备本地信息，请通过支持页面提交请求。请勿在公开工单中提供 API Key 或金融账户资料。功能或数据处理发生重大变化时，本页会更新生效日期。
