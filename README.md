# AutoGolden iOS 发布中心

这里仅保存 AutoGolden 的 iPhone/iPad 发布资料：安装包、发行说明、校验值、隐私政策及支持信息；不包含应用源代码。

## 当前发布状态

- 待发布版本：0.6.2（build 9）
- 支持范围：iPhone 与 iPad，iOS 26.6.1 或更高版本
- 安装方式：将通过 TestFlight 提供受 Apple 分发签名保护的测试版本；获批后通过 App Store 发布正式版。
- 安装包：尚待在付费 Apple Developer Program 的签名环境完成归档。归档成功后会在本仓库 `downloads/` 目录提供相应文件及 SHA-256 校验值。
